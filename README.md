# Fantacampionato Sammarinese

Fantasy football sul Campionato Sammarinese di calcio: asta a crediti, rose, formazioni
settimanali, scontro diretto — **senza pagelle**. I voti (Voto Titano) sono calcolati da
eventi oggettivi del referto FSGC.

## Contenuto del repository

- [`design/`](design/README.md) — progettazione visiva e funzionale dell'app: identità,
  design system, architettura informativa, schermate, area admin, token e prototipo
  navigabile (`design/index.html`, apribile direttamente nel browser).
